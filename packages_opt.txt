# Paquetes opcionales: install.sh pregunta antes de instalarlos (todos, ninguno o uno a uno).
# Los que ya están instalados no se preguntan, y update.sh no los toca: si desinstalas uno,
# no vuelve. Van con paru, así que pueden ser de los repos o de AUR.
# Uno a uno pregunta por cada paquete, salvo los de un grupo: los que van tras una cabecera
# "## Nombre" (con dos #), hasta la siguiente línea vacía, se preguntan todos juntos.
# Las extensiones de Visual Studio Code no van aquí sino en apps/vscode/extensions.txt: si VS Code
# está instalado, install.sh las instala todas sin preguntar.

# Apps
kate            # Editor de texto estilo notepad
nemo            # Un explorador de archivos que me funciona mejor que dolphin
file-roller     # Para poder comprimir/descomprimir
nemo-fileroller # Extensión para que nemo pueda comprimir/descomprimir
unzip           # Paquete unzip para que file-roller descomprima zip
zip             # Paquete zip para que file-roller comprima zip
imv             # Visor de imagenes minimalista
vlc             # Reproductor de vídeo y audio que abre casi cualquier formato
vlc-plugins-all # Todos los plugins y códecs opcionales de VLC (sin él, algunos formatos no se reproducen)
noto-fonts-emoji        # Emojis de color para las apps (Chrome, Zen, Teams, Kate...). La barra ya no los usa: solo glifos de la Nerd Font

## LaTeX (con la extensión LaTeX Workshop de Visual Studio Code, ver apps/vscode/extensions.txt)
texlive-basic             # Lo básico de LaTeX (antes se llamaba texlive-core)
texlive-latexextra        # Paquetes de LaTeX adicionales
texlive-binextra          # Programas auxiliares (latexmk, que usa LaTeX Workshop para compilar)
texlive-bibtexextra       # Estilos y paquetes extra de bibliografía (biblatex...)
biber                     # Procesa la bibliografía de biblatex (el sustituto de bibtex)
texlive-fontsrecommended  # Fuentes recomendadas (las Type 1 de las fuentes estándar, para el PDF)
texlive-plaingeneric      # Paquetes genéricos (válidos para LaTeX y plain TeX) que piden otros paquetes

euro-office-bin         # Euro-Office: suite ofimática (fork de ONLYOFFICE) para documentos, hojas de cálculo y presentaciones
